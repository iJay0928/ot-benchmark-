## 安装与基本检查

在仓库根目录打开PowerShell，建议Python 3.11：

```powershell
cd ot_benchmark
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m pip install pytest POT==0.9.6.post1
$env:POT_BACKEND_DISABLE_TENSORFLOW='1'
$env:OMP_NUM_THREADS='1'
$env:OPENBLAS_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
.\.venv\Scripts\python.exe -m pytest -q
```

以上是安装入口，不是完整依赖锁；历史实验使用Python 3.11.9和POT 0.9.6.post1。新机器的全部测试尚未验证，如测试依赖本地数据应按报错补充输入，不应将缺数据写成算法失败。

## 共享范围和复现限制

此仓库用于共享代码和研究进展，不是本机目录的完整备份。不包含原始压缩包、环境、数据缓存、第三方完整仓库、历史大矩阵、模型缓存和源码快照ZIP。汇总中的哈希保留原始证据含义，但不能仅凭仓库内汇总完成所有历史审计。

部分脚本需要先运行对应的输入生成器；跨轮读取历史输入的实验需要由项目负责人提供相应输入或重新生成到新的输出目录。保留原始实验目录，重跑不要覆盖旧结果。真实数据使用及再分发条件见[数据来源记录](ot_benchmark/research/真实数据来源与使用记录.md)。MovieLens原始数据不在仓库分发。

## 成员协作方式

每项工作使用独立分支，例如`research/stage-budget`。提交时写明修改内容和验证结果，通过Pull Request或Merge Request讨论后合并。实验报告注明数据身份、预算、质量标准、成功与失败数量；重复计时不能当作独立样本。新方案先保留实验开关，不直接替换默认求解流程。

本仓库暂未指定开源许可证；上传到托管平台不代表已授权对外开源。建议先使用私有仓库并由负责人邀请成员。
