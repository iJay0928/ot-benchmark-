# 最优性与状态变化诊断

2026-10-06。用于解释求解状态，不是新求解算法，也不自动改变历史实验验收规则。

## 数值原始—对偶差

固定正则强度 epsilon，采用目标

`F(P) = sum(C*P) + epsilon * sum(P*(log(P)-1))`。

零元素按 `0*log(0)=0` 处理。它包含熵项，与此前报告的运输成本 `sum(C*P)` 是不同指标，不能直接混用。

对任意有限势 f、g，其对偶目标为

`D(f,g) = a·f + b·g - epsilon * sum(exp((f_i+g_j-C_ij)/epsilon))`。

普通缩放中使用 `f=epsilon*log(u)`、`g=epsilon*log(v)`。由于当前计划未必满足边缘约束，不能直接把它的目标当作可行原始上界。先构造可行修正计划 Q，再计算 `F(Q)-D(f,g)`。在精确算术下由弱对偶性有 `D <= F* <= F(Q)`；本实现为双精度数值诊断，不是经过区间算术认证的严格证书。

计划修正采用已有的先行后列缩小、再补足剩余边缘质量的方法，依据 Altschuler、Weed、Rigollet 的 Algorithm 2；本次已查看原始论文该算法及说明：[NeurIPS 2017 原文](https://proceedings.neurips.cc/paper/2017/file/491442df5f88c6aa018e86dac21d3606-Paper.pdf)。这是既有方法，不记为自主创新。

## 两个状态变化指标

- 计划变化：相邻记录间当前计划的 L1 差。
- 势变化：先消除 f、g 可相互加减常数的自由度，令 `f'=f-(a·f)`、`g'=g+(a·f)`，再记录相邻时刻两组势变化的最大绝对值。

记录间隔通常为 250 次，最后一次可能更短，必须连同实际间隔解释。变化小不能单独证明已收敛；变化大也不能单独证明切换有收益。

## 实现检查

可行修正要求修正计划的最大边缘 L1 残差<=1e-12；原始求解是否通过仍按未修正计划的 1e-9 判断。目标差保留原值，不把负数简单截为零；低于 -1e-10 则报错。

测试包含零矩阵与不平衡计划的修正、零代价问题的解析最优值、势的常数变换不影响对偶值、二维非零代价问题与独立一维数值最小化结果的上下界比较。修正可能增加非零元素，需要构造完整活动计划，因此尚不能称为低开销在线特征或稀疏内存方法。
