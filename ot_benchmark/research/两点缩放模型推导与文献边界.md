# 两点缩放模型推导与文献边界

2026年10月10日。以下是标准Sinkhorn迭代在两点模型下的代数推导，用于建立解释基线，不主张新定理或新的局部收敛率理论。

## 模型与精确解

a=(A,B)，B=1−A；b=(A+δ,B−δ)，0<A<1，0≤δ<B。C=[[0,c],[c,0]]，c>0，k=exp(−c/ε)>0。计划的可行形式为P=[[A−t,t],[t+δ,B−δ−t]]，0<t<min(A,B−δ)。对熵正则目标求导可得：

    t(t+δ) = k²(A−t)(B−δ−t)

令q=k²，L=δ+q(1−δ)，其正根可稳定写为：

    t = 2qA(B−δ) / [L + sqrt(L²+4(1−q)qA(B−δ))]

这是严格凸目标的一阶条件推论，是小问题参考解，不是算法创新。

## 一整次行列缩放的精确映射

令r=v1/v2，s=(A+δ)/(B−δ)，先行缩放再列缩放得到：

    T(r) = [s(B+Ak²)r + sk] / [kr + A+Bk²]

这是Möbius映射，记其2×2系数矩阵为M。正、负固定点为r+、r−，局部收缩因子为：

    ρ = det(M)/(M21 r+ + M22)²
      = det(P*)² / [AB(A+δ)(B−δ)]

对初值r0，交比满足w_j = [(r0−r+)/(r0−r−)]ρ^j，从而r_j=(r+−w_j r−)/(1−w_j)。因此可以闭式计算第百万步状态，不必真的执行百万次高精度循环。这是标准迭代的等价计算，不是提出一个更快的通用OT求解器。

## 初始状态与局部收缩需要同时看

A=B=.5、δ=0时r+=1，v=(1,1)的比例已在固定点，一整次缩放得到最优计划。这不能说明此时所有初值都快：ρ=((1−k)/(1+k))²，k很小时非常接近1。

固定δ>0、k趋于0时，ρ趋于(.5−δ)/(.5+δ)，故1−ρ约为4δ。与此同时log r+约为c/ε+log[δ/(.5−δ)]，从r0=1出发可能远离局部区域。在跨簇耦合可忽略的早期，log r每步约增加log[(.5+δ)/(.5−δ)]。两者合在一起解释为什么不能仅用局部收缩率预测从初值出发的总耗时；这个近似不是全程误差界或最优调度规则。

相反，δ=0时给log r0加小扰动，势差可能很久不消失，但运输计划与目标值仍可能非常接近最优。因此本轮不能用势差误差代替正式数值原始对偶间隙，也不能将“势差未收敛”直接记为求解失败。
