# 表示误差与目标误差关系

日期：2026-10-07；第 23 轮；仅离线诊断，未改变求解或验收策略。

## 要解决的问题

现有触发使用两种浮点表示的 L1 距离，阈值 1e-8 的单位与原始—对偶间隙不同。将这两种数值直接比较，不能解释为什么应当切换。这里先建立同一目标函数单位下的误差估计，而不根据四个已知案例重新选阈值。

## 推导及限制

记直接核缩放矩阵为 P，对数势重建矩阵为 R。分别舍入到目标边缘后得到 QP、QR。为使用概率分布熵的连续性不等式，在诊断内部将两个舍入矩阵各除以总质量，得到 q、r。这一步仅用于分析，不改变求解器输出；记录归一化前后目标差之差的绝对值 δ。

设 N 为矩阵元素数，T=||q-r||₁/2，h(T)=-T ln T-(1-T)ln(1-T)，约定 0 ln 0=0。对于 N>1，

|F(QR)-F(QP)| ≤ (max C-min C)T + ε[T ln(N-1)+h(T)] + δ = BP。

N=1 时熵差为零。F(Q)=〈C,Q〉+εΣ Q(ln Q-1)。线性部分来自等质量分布的总变差界，熵部分来自 Audenaert 的连续性不等式（将以 2 为底的对数换成自然对数）。这里 δ 显式计入浮点舍入后总质量不恰为 1 的影响。

真实对偶表达式使用 R：DR=ε(a·lu+b·lv-ΣR)。用 P 替代 R 得到的 DP 仅是代理量，不保证是原问题的合法下界。二者差满足 |DR-DP|≤ε||R-P||₁=BD。

因而真实间隙与代理间隙之差的绝对值不超过 B=BP+BD。代码同时记录实际观察到的差 |F(QR)-F(QP)+ε(ΣR-ΣP)|。

这个界约束的是两种表示造成的间隙差异，**不约束当前解的总最优性误差，也不证明继续普通迭代必然失败**。B 超过验收容差，仅表示这个上界不足以排除显著表示误差；不能反推实际误差也超过容差。实现使用普通浮点运算，不是区间算术证书，极小值受消减误差影响。

## 现有工作与创新边界

- Audenaert，Theorem 1：熵连续性界及经典概率分布情形。原文：https://arxiv.org/pdf/quant-ph/0610146 。本项目引用既有不等式，不主张新定理。
- Schmitzer，Section 3.3，Propositions 10–11：已经研究核截断对原始—对偶间隙的影响，并结合稳定化控制误差。原文：https://arxiv.org/pdf/1610.06519 。不能将“考虑截断误差并稳定化”整体宣称为首创。

目前的区别仅是针对两条浮点计算路径的事后诊断与策略选择场景；是否构成可发表的方法贡献，仍需更强对照、开销及独立边界实验，尚未完成新颖性证明。
