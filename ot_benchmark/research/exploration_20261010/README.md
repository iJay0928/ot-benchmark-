## 复现文档生成

`build_share_doc.py` 使用 `python-docx`，不依赖项目求解器或个人机器的绝对路径。生成文件在脚本同目录；仓库内已验收Word版位于上面的阅读入口，重建后仍需独立检查分页。

```powershell
python -m pip install python-docx
python ot_benchmark/research/exploration_20261010/build_share_doc.py
```

本轮验收Word版SHA256：`31be5f039bbcb76952853d01185005c1302d84d93222d2b176f9b2f53f32575e`。重新生成DOCX的容器元数据可能变化，不要求字节哈希相同。

## 可选的文献发现重跑

`search_literature.py` 依赖外部安装的双引擎工具 `hybrid_scholar.py` 及其依赖和服务配置，工具本体与凭据不随仓库分发。提供自己的工具目录，并使用新输出路径；脚本拒绝覆盖原始证据。已有JSON可直接阅读，无需先配置该工具。

```powershell
python ot_benchmark/research/exploration_20261010/search_literature.py --skill-scripts "你的论文搜索工具脚本目录" --output "新输出目录/literature_discovery_rerun.json"
```

重跑会访问论文检索服务，可能因时间与服务覆盖不同返回不同结果；双源收录并不证明新颖性或论文结论正确。正式推进前，针对选定路线补齐最接近3至5篇论文的全文差异表。
